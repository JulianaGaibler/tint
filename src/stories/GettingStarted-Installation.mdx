# Installation

Tint is a design system for Svelte and Astro projects, providing components,
fonts, icons, and styles.

## Install the package

Install Tint from GitHub using npm:

```bash
npm install github:JulianaGaibler/tint
```

Or with pnpm:

```bash
pnpm add github:JulianaGaibler/tint
```

## Requirements

Tint requires the following to work properly:

- Svelte 5+, since Tint components are built with Svelte 5 using runes syntax
- A SASS compiler, since styles are provided as SASS source files (not
  pre-compiled CSS)
- A modern bundler such as Vite or Webpack to handle asset imports (developed
  and tested with Vite)

## Configuration for Astro projects

### TypeScript path mappings (tsconfig.json)

Add path mappings to help TypeScript resolve Tint imports:

```json
{
  "extends": "astro/tsconfigs/strict",
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@src/*": ["src/*"],
      "tint/*": ["node_modules/tint/dist/*"]
    }
  }
}
```

### Vite configuration (astro.config.mjs)

Configure Vite to properly handle Tint in SSR builds:

```javascript
import svelte from '@astrojs/svelte'
import { defineConfig } from 'astro/config'
import path from 'node:path'
import { createRequire } from 'node:module'

const require = createRequire(import.meta.url)
// Resolve Tint's location so ~tint works with pnpm, hoisting, and monorepos
const tintDist = path.dirname(require.resolve('tint'))

export default defineConfig({
  vite: {
    ssr: {
      // Important: If not set, this can lead to style import errors in Astro
      noExternal: ['tint*'],
    },
    resolve: {
      alias: {
        // Allow using ~tint/fonts in SASS imports
        '~tint': tintDist,
        '@src': '/src',
      },
    },
  },
  integrations: [svelte()],
})
```

What each part does:

- `noExternal: ['tint*']` bundles Tint during SSR, preventing module resolution
  errors
- The `'~tint'` alias resolves `~tint/fonts` in SASS `@font-face` declarations
  to Tint's `dist` folder. Using `require.resolve` instead of a hardcoded
  `node_modules/tint/dist` path keeps it working under pnpm and in monorepos
- The `@src` alias is a shorthand for project imports (optional but recommended)
